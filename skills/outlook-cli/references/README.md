# Outlook CLI References

Behavioral guidance and quirks documentation for the `outlookcli` command-line tool.

**Note for developers:** Run `dotnet build -c Release` to generate `SKILL.md` and copy shared
content from `skills/shared/` into this folder. Edit `skills/shared/`, never the copies here.

**Note for users:** When distributed as a skill package, this folder is pre-populated with all
necessary reference files.

## Contents

- `cli-commands.md` - generated command reference for all 8 tools
- `behavioral-rules.md` - core execution rules (copied from `skills/shared/`)
- `outlook-workflows.md` - common worked workflows (copied from `skills/shared/`)

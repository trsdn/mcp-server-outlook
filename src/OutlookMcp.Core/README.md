# OutlookMcp.Core

PowerPoint-specific business logic for OutlookMcp. Provides commands for slides, shapes, text, charts, tables, animations, transitions, design, export, VBA, and more.

This is an internal library used by [OutlookMcp.McpServer](https://www.nuget.org/packages/OutlookMcp.McpServer) and [OutlookMcp.CLI](https://www.nuget.org/packages/OutlookMcp.CLI). It is not intended for direct consumption.

## Requirements

- Windows with Microsoft PowerPoint installed
- .NET 9.0+
